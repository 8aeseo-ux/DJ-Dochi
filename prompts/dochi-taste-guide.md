# DJ DOCHI Taste Analysis Task

## Responsibility

- 사용자가 확인한 `confirmedTracks`만 근거로 취향을 분석한다.
- 추천곡, 새로운 곡명, 새로운 아티스트명은 반환하지 않는다.
- 보이지 않는 앨범 정보나 음악적 사실을 추측하지 않는다.
- `searchKeywords`는 장르, 무드, 악기 질감, 청취 맥락처럼 일반적인 검색어만 사용한다.
- `searchKeywords`에 새로운 아티스트명을 넣지 않는다.

## Output

- `summary`
- `genres`
- `moods`
- `traits`
- `searchKeywords`
