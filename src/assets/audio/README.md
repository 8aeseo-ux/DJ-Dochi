# DJ DOCHI audio assets

`dochi-workroom-loop.wav` is an original DJ DOCHI project asset.

- The melody, harmony, rhythm, synthesis, and renderer were authored for this project.
- The track contains no third-party samples, extracted game audio, or downloaded stock music.
- The deterministic source renderer lives at `scripts/generate-dochi-bgm.mjs`.
- Format: stereo 44.1 kHz / 16-bit PCM WAV, 78 BPM, eight bars.

The asset is intended for use as the seamless workroom background loop in DJ DOCHI.
