# DJ DOCHI 포먼트 캐릭터 보이스 설계

## 목표

현재의 짧은 신시사이저 전자음을 작은 생물이 실제로 웅얼거리며 말하는 듯한 캐릭터 보이스로 교체한다. 명확한 단어나 TTS는 사용하지 않으며, `뿌`, `부`, `도`, `모`처럼 둥근 음절감을 목표로 한다.

기존 자막 속도, 2~3글자 간격의 재생 규칙, 감정 상태, SFX 설정, 대화 건너뛰기 동작은 유지한다. OCR, 취향 분석, 추천, LP와 카메라 흐름은 변경하지 않는다.

## 선택한 방식

외부 음원 파일 대신 Web Audio API로 절차적 포먼트 보이스를 생성한다.

1. 낮고 짧은 유성 성대 진동에 가까운 excitation 파형을 만든다.
2. 소량의 부드러운 breath noise를 섞어 생물성 질감을 추가한다.
3. `우/오` 계열의 모음에 가까운 세 개의 포먼트 대역으로 병렬 필터링한다.
4. 필터 출력을 합친 뒤 저역통과 필터와 컴프레서를 거쳐 날카로움과 피크를 억제한다.
5. 대사·문자 인덱스에 기반한 결정적 변조로 피치와 길이를 조금씩 바꾼다.

이 방식은 음원 라이선스나 네트워크 로딩 없이 현재 엔진 구조를 유지하면서, 단일 사인파보다 말소리에 가까운 질감을 제공한다.

## 음색

- 기본 성대 주파수는 현재보다 조금 낮고 둥글게 유지한다.
- 사인파와 삼각파 비중을 줄이고 완만한 glottal pulse와 저역 처리된 노이즈를 중심으로 excitation을 만든다.
- 포먼트 중심 주파수는 `우/오` 계열을 기준으로 설정 파일에 분리한다.
- 세 번째 포먼트는 작은 비율로만 사용해 자음처럼 날카롭게 들리지 않게 한다.
- 아주 약한 saturation과 dynamics compression으로 작은 생물의 밀도감만 추가한다.

## 길이와 볼륨

- 기본 재생 길이: 약 110ms
- 일반 음절 변동: 약 ±7%
- 문장 마지막 유효 글자: 약 140ms
- master gain: 현재 체감 볼륨의 약 1.7배
- 컴프레서를 사용해 여러 환경에서 피크가 튀거나 찢어지는 현상을 방지한다.

문장 마지막 글자는 기존 타이핑 완료 시점을 변경하지 않고, 재생 파라미터에 terminal 여부만 전달해 길이를 늘린다.

## 랜덤성과 감정

모든 변동은 같은 대사에서 재렌더링될 때 결과가 달라지지 않도록 dialogue key와 문자 인덱스로 결정한다.

- 피치 변동: 약 ±18~24 cents
- 길이 변동: 약 ±7%
- 포먼트 변동: 약 ±3%
- neutral: 기준값
- surprised: 조금 높고 빠르게
- thinking: 조금 낮고 느리게
- proud: 조금 밝고 경쾌하게
- error: 조금 낮게

감정 차이는 기본 음색을 바꾸지 않고 피치와 속도에만 미세하게 적용한다.

## 재생 흐름

1. `DialogueBox`가 글자를 표시한다.
2. 공백·줄바꿈·문장부호를 제외한 유효 글자만 cadence 계산에 포함한다.
3. 2글자 또는 3글자 간격으로 `useDochiVoice`에 재생을 요청한다.
4. 현재 글자가 문장의 마지막 유효 글자인지 함께 전달한다.
5. 엔진이 감정·문자별 변조와 terminal 길이를 적용해 하나의 짧은 음절을 재생한다.
6. 새 음절이 시작되거나 대사를 건너뛰면 이전 음절을 짧게 감쇠한 뒤 중지한다.

- 기본/terminal 길이 차이
- 볼륨 및 컴프레서 설정

- 문자별 결정적 랜덤성
- 2~3글자 cadence와 문장부호 제외
- 마지막 유효 글자 판정
- 대사 건너뛰기 및 SFX off 시 즉시 중지
- 기존 전체 테스트, TypeScript, 프로덕션 빌드
- 로컬 데스크톱 브라우저와 모바일 Safari 정책을 고려한 사용자 제스처 unlock 확인

## 완료 기준

- 전자 악기보다 둥근 생물성 웅얼거림에 가깝게 들린다.
- 현재보다 명확히 크지만 대사를 방해하지 않는다.
- 일반 음절은 약 100~120ms, 마지막 음절은 더 길게 끝난다.
- 반복적인 기계음으로 들리지 않도록 피치와 길이가 미세하게 변한다.
- 기존 기능과 상태 흐름에 회귀가 없다.
- 로컬 서버에서 사용자가 직접 청음할 수 있다.
