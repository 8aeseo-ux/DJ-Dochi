# Shared Action Button Typography Design

## Goal

DJ DOCHI의 오류, 검수, 카메라, 결과 화면에 등장하는 공통 액션 버튼 글자를 현재 대화 선택지와 같은 크기와 굵기로 통일한다. 버튼의 크기와 기능은 유지하면서 텍스트의 시각적 무게만 낮춘다.

## Typography

- Font size: `0.9rem`
- Font weight: `500`
- 기존 고딕 글꼴과 색상은 유지한다.
- 버튼의 높이, 패딩, 테두리, 배경, 아이콘 크기와 인터랙션은 변경하지 않는다.

## Scope

공통 스타일을 사용하는 다음 버튼에 적용한다.

- 모든 `RetroButton`
- 음악 플랫폼 액션 버튼
- OCR 및 취향 분석 오류 화면의 재시도·대체 입력 버튼
- 추출 결과 검수, 카메라 촬영·검토, 최종 결과 화면의 텍스트 액션 버튼

다음 요소는 제외한다.

- 닫기·삭제 등 아이콘만 있는 버튼
- 이미지 업로드 드롭존 자체
- LP와 믹스테이프처럼 오브젝트 역할을 하는 인터랙션 버튼

## Implementation Boundary

`sketch-theme.css`의 공통 액션 버튼 규칙에서 타이포그래피를 한 번만 정의한다. 선택지 전용 규칙에 중복된 글자 크기와 굵기는 제거하여 이후 화면이 같은 기준을 자동으로 따르게 한다. JSX, 상태 흐름, 이벤트 처리 및 컴포넌트 구조는 수정하지 않는다.

## Verification

- 공통 액션 버튼이 `0.9rem`, `500`으로 계산되는지 스타일 테스트로 확인한다.
- 선택지 전용 규칙에 중복 타이포그래피가 남지 않았는지 확인한다.
- 기존 전체 테스트, TypeScript 검사, 프로덕션 빌드를 실행한다.
- 데스크톱과 모바일에서 버튼 텍스트가 잘리거나 의도하지 않게 줄바꿈되지 않는지 확인한다.
