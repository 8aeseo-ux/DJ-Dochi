# DJ DOCHI Sketchbook Work Note Theme

## 목적

DJ DOCHI의 기능과 인터랙션 흐름은 유지하면서, 현재의 종이 콜라주형 UI를 한 장의 스케치북에 직접 기록한 음악 작업 노트처럼 바꾼다.

완성된 서비스 화면보다 음악을 좋아하는 사람이 곡을 듣고, 메모하고, 지우고, 다시 적으며 만든 개인 노트처럼 보여야 한다.

## 확정된 방향

선택된 시각 방향은 **자연색 잉크 노트**다.

- 도치와 DJ 컨트롤러의 기존 이미지와 자연색을 유지한다.
- 캐릭터와 장비에 적용된 흰 스티커 외곽선, 테이프, 두꺼운 그림자를 제거한다.
- 이미지는 별도의 종이 조각이 아니라 스케치북 페이지에 바로 인쇄된 것처럼 배치한다.
- UI는 하나의 크림색 노트 페이지 위에 펜, 연필, 옅은 색연필로 기록한 것처럼 표현한다.

## 범위

### 포함

- 전체 배경과 고정 작업실
- 버튼, 입력창, 패널, 대화창, 선택 메뉴
- 업로드 패널과 OCR 검수 화면
- 분석 상태와 오류 화면
- LP 인터랙션과 에너지 표시
- 카메라, 촬영 검수, 폴라로이드 생성 화면
- 최종 믹스테이프와 음악 플랫폼 버튼
- 데스크톱 및 모바일 반응형 스타일
- `prefers-reduced-motion` 대응

### 제외

- React 상태 흐름 변경
- OCR, LLM, 카탈로그 검증, 카메라, LP 물리 로직 변경
- API 요청·응답 구조 변경
- 캐릭터 이미지 교체 또는 새 캐릭터 생성
- 페이지 이동이나 새로운 기능 추가
- 컴포넌트 구조의 대규모 변경

## 시각 시스템

### 페이지

- 전체 경험은 여러 장의 종이를 겹친 구성이 아니라 하나의 큰 스케치북 페이지다.
- 바탕은 밝은 크림색이며, 아주 옅은 노트 가로선과 한쪽 세로 기준선만 사용한다.
- 종이 질감은 작은 점과 미세한 명암 차이로 표현하며 강한 노이즈나 접힌 종이 효과는 사용하지 않는다.
- 여백을 충분히 남기고, 낙서는 빈 공간을 설명하거나 시선을 연결할 때만 배치한다.

### 선과 프레임

- 모든 주요 선은 완벽한 직선 대신 1~2px 두께의 잉크 선을 사용한다.
- 패널은 배경색이 다른 카드가 아니라 페이지 위에 직접 그린 불규칙한 프레임으로 표현한다.
- 프레임의 모서리와 회전값을 아주 조금씩 달리해 손으로 그린 느낌을 만든다.
- 이중 그림자, 떠 있는 카드 효과, 두꺼운 스티커 테두리는 사용하지 않는다.

### 색

- 기본색은 크림색 종이, 짙은 흑연색, 연필 회색이다.
- 강조색은 바랜 빨강, 연한 초록, 옅은 파랑, 연한 노랑을 제한적으로 사용한다.
- 강조색은 넓은 면을 채우기보다 밑줄, 체크, 작은 상태 표시, LP 라벨에만 사용한다.

### 글꼴

- 제목, 도치 대사, 짧은 메모와 낙서에는 번들된 한글 손글씨 글꼴 `Gaegu`를 사용한다.
- 긴 설명, 입력값, 곡 정보와 오류 메시지는 기존의 가독성 높은 본문 글꼴을 유지한다.
- 글꼴은 런타임 외부 요청에 의존하지 않도록 프로젝트 번들에 포함한다.

### 도치와 DJ 컨트롤러

- 기존 자연색 이미지를 유지한다.
- 채도와 대비만 미세하게 낮추고, 배경과 섞이도록 가벼운 `mix-blend-mode` 또는 투명도 조정을 적용한다.
- 흰색 스티커 외곽선, 마스킹테이프 가상 요소, 떠 있는 그림자를 제거한다.
- 위치와 크기, 상태별 이미지 전환, idle 프레임 애니메이션은 변경하지 않는다.

## 컴포넌트별 표현

### 버튼

- 채워진 웹 버튼보다 손으로 둘러 그린 텍스트 버튼에 가깝게 표현한다.
- 기본 상태는 투명한 종이 배경과 불규칙한 잉크 프레임을 사용한다.
- 주요 행동만 옅은 색연필 면으로 강조한다.
- hover 시 1~2px 흔들림과 연필 밑줄이 나타난다.
- active 시 `translateY(1px)` 정도로 종이를 톡 누르는 반응만 사용한다.

### 대화창과 선택 메뉴

- 별도의 카드처럼 띄우지 않고 페이지 하단에 손으로 그은 프레임으로 표현한다.
- 화자 이름은 작은 손글씨 메모로 처리한다.
- 다음 표시와 선택지 주변에는 최소한의 화살표 또는 체크 낙서를 사용한다.

### 입력과 OCR 검수

- 입력창은 옅은 노트 줄 위에 직접 쓰는 영역처럼 표현한다.
- 곡 목록은 카드 목록 대신 손으로 정리한 체크리스트 형태로 보인다.
- 삭제 버튼은 작은 취소선 또는 동그라미 친 `×` 형태로 표현한다.
- 경고와 개인정보 안내는 페이지 여백의 연필 메모처럼 표시한다.

### LP 인터랙션

- 기존 포인터 각도 계산과 물리 로직은 그대로 유지한다.
- LP는 화면에서 유일하게 진한 검은 면을 가진 핵심 오브젝트로 유지한다.
- 속도선, 에너지 게이지, REC 표시는 펜으로 빠르게 그린 선과 색연필 표시처럼 바꾼다.
- 과속 흔들림은 기존 동작을 유지하되 시각적으로 과장하지 않는다.

### 카메라와 폴라로이드

- 촬영 화면은 기능상 모달을 유지하지만, 모달 패널은 노트 위에 그린 큰 프레임처럼 표현한다.
- 폴라로이드 결과 자체는 기능적 소품이므로 유지하되 마스킹테이프 장식은 제거한다.
- 사진 주변의 메모와 날짜, `DJ DOCHI & YOU` 문구를 손글씨로 표현한다.

### 최종 믹스테이프

- 믹스테이프 카드 전체를 별도 종이 조각처럼 띄우지 않는다.
- 페이지 안의 완성 기록 영역으로 표현하고, 곡 목록은 손으로 정리한 트랙리스트처럼 보이게 한다.
- 플랫폼 버튼은 작은 손글씨 링크 또는 동그라미 친 선택지 형태로 통일한다.
- 검증 상태는 작은 체크 표시와 짧은 메모로 표시한다.

## 낙서 규칙

- 낙서는 장식 밀도를 높이기 위한 반복 패턴으로 사용하지 않는다.
- 화면당 눈에 띄는 낙서는 3~6개 범위로 제한한다.
- 허용 요소는 화살표, 별, 체크, 음표, 짧은 밑줄, 지운 흔적, 한 줄 메모다.
- 인터랙션 요소와 텍스트를 가리지 않으며 `pointer-events: none`을 적용한다.
- 상태별 핵심 행동 근처에만 의미 있는 낙서를 배치한다.

## CSS 구조

- `src/styles/sketch-theme.css`를 기존 스타일 뒤에 불러오는 독립 테마 레이어로 유지한다.
- 기존 레이아웃 치수와 상태 클래스는 재사용한다.
- 공통 토큰은 `:root` CSS 변수로 정의한다.
- 프레임, 잉크 선, 메모 글꼴, 제한된 강조색을 공통 규칙으로 묶는다.
- CSS 가상 요소로 구현 가능한 낙서는 JSX에 추가하지 않는다.
- 특정 상태에서 CSS만으로 표현할 수 없는 장식이 필요한 경우에만 비기능성 클래스 또는 장식 요소를 최소 추가한다.

## 상호작용과 접근성

- hover와 active 효과는 기능적 피드백을 유지하면서 1~2px 범위로 제한한다.
- 키보드 포커스는 손으로 그린 이중 밑줄 또는 옅은 파랑 외곽선으로 명확하게 표시한다.
- 색상만으로 상태를 전달하지 않고 텍스트, 체크, 오류 문구를 함께 유지한다.
- `prefers-reduced-motion: reduce`에서는 흔들림, 회전 변화, 낙서 애니메이션을 제거한다.

## 오류 및 데이터 흐름

이 변경은 시각 테마에만 적용한다. OCR 실패, 취향 분석 실패, 카탈로그 실패, 카메라 권한 거절 등 기존 오류 상태와 재시도 흐름은 변경하지 않는다. 오류 문구의 의미와 버튼 동작도 유지한다.

## 검증

- 테마 소스 테스트에서 콜라주 장식 제거와 새 노트 토큰 적용을 확인한다.
- 기존 전체 컴포넌트 및 흐름 테스트를 실행한다.
- TypeScript 검사를 실행한다.
- 프로덕션 빌드를 실행한다.
- 데스크톱과 모바일 크기에서 다음 상태를 시각 확인한다.
  - idle 및 대화
  - 업로드 및 텍스트 입력
  - OCR 검수와 오류
  - 취향 분석
  - LP 인터랙션 및 녹음
  - 카메라와 촬영 검수
  - 최종 믹스테이프

## 완료 기준

- 화면이 여러 종이 조각을 붙인 콜라주가 아니라 한 장의 연속된 작업 노트처럼 보인다.
- 도치와 DJ 컨트롤러의 기존 캐릭터성과 상태 변화가 유지된다.
- 기능, 상태 흐름, 반응형 레이아웃에 회귀가 없다.
- 손그림 스타일이 버튼, 입력, 패널, 오류, LP, 카메라, 결과까지 일관되게 적용된다.
- 장식보다 여백과 직접 그린 선의 매력이 먼저 느껴진다.
